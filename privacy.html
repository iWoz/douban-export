Chrome 扩展程序：豆瓣导出助手 Plus（Douban Export Plus）
生效日期：2026 年 11 月 11 日  ·  最后更新：2026 年 11 月 12 日
一句话总结：本扩展不收集、不上传、不共享你的任何数据。 它只在你自己的浏览器里，把你打开的豆瓣读书、电影或音乐个人页中可见的列表信息整理成 Excel 文件并保存到你自己的电脑上。 扩展不包含任何统计、广告或第三方跟踪代码。

1. 我们是谁

本扩展由个人开发者（以下简称“开发者”“我们”）开发并发布。它是一个纯前端工具： 在豆瓣读书、电影、音乐个人主页及状态列表页的页面标题后添加导出按钮，帮助你把当前站点的三个状态列表整理成 Excel：读书的「在读 / 读过 / 想读」、电影的「在看 / 看过 / 想看」、音乐的「在听 / 听过 / 想听」。

本扩展与豆瓣（douban.com）没有任何隶属、合作或授权关系， “豆瓣”是其权利人的商标，本文仅用于说明扩展的适用站点。

2. 扩展处理哪些信息

扩展运行时会在你的浏览器中读取以下信息，目的仅为生成你主动点击导出的 Excel 文件：

信息来源用途
列表条目：书名及出版信息、片名及影片信息、专辑名及音乐信息；各条目的评分、短评、标签、状态、标记日期、豆瓣链接与封面地址 你在当前浏览器中打开的 book.douban.com、movie.douban.com 或 music.douban.com 个人列表页面 写入你点击导出的 Excel 文件
当前个人页面对应的豆瓣用户 ID 你正在访问的个人页面地址（/people/<用户ID>/） 拼接当前站点的列表分页地址；区分本地状态记录；作为导出文件名的一部分
“请求间隔”设置、状态日期记录（书籍、电影和音乐各状态的日期，按内容类型和豆瓣用户 ID 分开保存） 扩展自身的设置页与导出过程 控制抓取速度；在后续导出时计算从想读 / 想看 / 想听或在读 / 在看 / 在听到完成的天数

扩展不会读取你的豆瓣账号密码、Cookies、登录凭据、私信、订单、支付信息或你在豆瓣以外的任何网页内容。它只读取导出列表所需的信息，包括列表中的短评。 它不在其他网站上运行。

3. 数据存储在哪里

“请求间隔”和“状态日期记录”保存在你浏览器的本地扩展存储中（Chrome 的 chrome.storage.local）， 只存在于你这台电脑上，不会同步到云端，也不会发送给我们或任何第三方。 新记录按内容类型和豆瓣用户 ID 隔离。旧版没有账号归属的书籍记录会保留并单独显示，但不自动用于新导出。你可以在设置页查看记录数量并清空所有新旧记录；清空记录会保留请求间隔设置。卸载扩展会删除全部扩展本地存储。

4. 数据是否会被上传或共享

  • 扩展没有任何用于接收数据的服务器、后端接口或账号体系；
  • 扩展不含任何统计 SDK、广告 SDK、崩溃上报或第三方跟踪代码；
  • 扩展不会将你的数据出售、出租、转让或以任何形式提供给任何第三方；
  • 扩展不会为广告、画像、信用评估等目的使用你的数据。

扩展仅在用户点击导出后，向当前所在的 book.douban.com、movie.douban.com 或 music.douban.com 发起请求，用于读取当前个人页面对应用户的列表分页， 请求不经过任何中间服务器。你导出的 Excel 文件由浏览器直接生成并保存到你的下载目录。

5. 权限说明

访问豆瓣读书、电影和音乐个人页面

内容脚本仅匹配 book.douban.com、movie.douban.com、music.douban.com 的 /people/* 和 /mine* 路径，以便插入导出按钮，并在点击后读取当前站点的列表内容。 除此之外不会访问其他网站，也不会在后台抓取页面。当你点击导出时，扩展会请求同一网站下当前个人列表的后续分页， 这与手动翻页的效果相同。

存储（storage）

用于保存“请求间隔”设置，以及按内容类型和豆瓣用户 ID 记录条目的状态日期，以便在后续导出时计算对应时长。全部保存在本地，不上传。

6. 第三方

扩展内打包了开源库 SheetJS（Apache-2.0 许可）用于在本地生成 Excel 文件， 该库完全在本地运行，不会发起网络请求或收集数据。 除此之外，扩展不集成任何第三方服务。

7. 儿童隐私

本扩展不是面向儿童的产品，也不会主动收集任何人的个人身份信息。

8. 你的选择

  • 不点击导出按钮，扩展不会请求任何列表分页；
  • 在设置页清空所有类型、所有账号的状态日期记录及旧版书籍记录；卸载扩展可删除包含请求间隔设置在内的全部本地数据；
  • 随时在 chrome://extensions 中禁用或移除本扩展。

9. 政策变更

如果扩展的功能或数据处理方式发生变化，我们会更新本页面并修改“最后更新”日期。 涉及数据收集方式的重大变更会在扩展更新说明中提示。
