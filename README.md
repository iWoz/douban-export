# 豆瓣导出助手 Plus

Chrome 扩展：在豆瓣「我读 / 我看 / 我听」个人主页旁加入导出按钮，**一次导出当前站点三个状态列表的全部分页，生成一个 Excel 文件**。

基于原「豆瓣导出助手」1.1 改造，支持书籍、电影和音乐。

## 功能

| 站点 | 入口按钮 | Excel 工作表 |
|---|---|---|
| 豆瓣读书 | 导出书单 (Excel) | 全部、在读、已读、想读、说明 |
| 豆瓣电影 | 导出片单 (Excel) | 全部、在看、已看、想看、说明 |
| 豆瓣音乐 | 导出音乐 (Excel) | 全部、在听、已听、想听、说明 |

按钮位于「读书主页 / 电影主页 / 音乐主页」导航旁，不必先进入某个状态列表；列表页也保留导出入口。每次只导出当前站点的内容。

| 字段 | 说明 |
|---|---|
| 书籍信息 | 书名、作者、出版社、出版年、定价、出版信息原文 |
| 电影信息 | 片名、影片信息原文 |
| 音乐信息 | 专辑名、音乐信息原文 |
| 状态 | 当前站点的在读 / 已读 / 想读等状态 |
| 我的评分(1-5) | 用户自己的星级，未评分为空 |
| 短评、标签 | 列表条目中的短评和标签 |
| 标记日期 | 豆瓣列表显示的当前状态日期 |
| 各状态日期、时长 | 已记录的想读 / 在读 / 读完日期及对应天数；电影、音乐使用对应名称 |
| 豆瓣链接、封面 | 可点击的条目链接及封面地址 |

书籍出版信息会拆分为独立字段，同时保留原文；电影和音乐保留列表中的完整信息原文。

## 状态日期与时长

豆瓣列表显示条目的**当前状态**日期。状态改变后，以前的日期可能无法再从列表中读取。

扩展在每次导出时，把条目各状态的日期记到浏览器本地存储（`chrome.storage.local`），按**内容类型 + 豆瓣用户 ID** 分开保存。以后再导出时，用已记录的日期计算从「想读 / 想看 / 想听」或「在读 / 在看 / 在听」到完成的天数。

- 在「想读 / 在读」等状态时导出过，之后完成再导出，就能利用之前记录的日期计算时长。
- 过去已经完成、又没有历史日期的条目，对应日期和时长留空。
- 建议隔一段时间导出一次，积累状态日期。设置页显示各类型的记录数量，可清空所有账号的状态记录。
- 升级前的 `dbxHistory` 书籍记录没有账号归属，会保留并单独显示，但不会自动用于新导出，以免混入其他账号的日期。

## 安装

1. 下载并解压 `dist/` 中的安装包，或克隆本仓库。
2. 打开 `chrome://extensions`，打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择解压目录或仓库目录。
4. 如果已有其他豆瓣导出扩展，可先停用，避免重复按钮。

更新后，在扩展管理页重新加载扩展，再刷新豆瓣页面。新版本增加电影、音乐站点访问范围，浏览器可能要求确认新增站点权限。

## 使用

1. 登录豆瓣，打开 [我读](https://book.douban.com/mine)、[我看](https://movie.douban.com/mine) 或 [我听](https://music.douban.com/mine)，也可以打开对应的 `/people/你的ID/` 个人主页或状态列表页。
2. 点击「读书主页 / 电影主页 / 音乐主页」旁的导出按钮；没有该导航的列表页会在标题旁显示按钮。
3. 等待当前站点三个状态列表抓取完成，点击「下载 Excel」。关闭进度窗口会中止本次导出。

请求间隔默认为 1 秒，可在扩展设置中调整。条目较多时建议调大间隔；豆瓣限制访问或要求登录时，请按提示处理后再试。

## 隐私

- 不收集、不上传、不共享数据；没有统计、广告或第三方跟踪代码。
- 处理在浏览器本地完成，Excel 由浏览器生成并下载。
- 请求间隔和状态日期记录保存在 `chrome.storage.local`，不向云端同步。设置页清空记录不会删除请求间隔设置。
- 仅使用 `storage` 权限，内容脚本仅匹配 `book.douban.com`、`movie.douban.com`、`music.douban.com` 的 `/people/*` 和 `/mine*` 页面。
- 完整说明见 [privacy.html](privacy.html)。

## 文件说明

- `manifest.json` — MV3 清单。
- `export.js` — 页面入口、抓取、解析、生成 Excel。
- `xlsx.full.min.js` — 本地打包的 SheetJS 社区版 0.20.3。
- `modal.css` — 导出按钮及进度弹窗样式。
- `options.html` / `options.js` — 请求间隔及状态日期记录设置。
- `privacy.html` — 隐私政策，可托管到 GitHub Pages。
- `PUBLISHING.md` — 上架时可用的权限理由和用途说明。
- `build.sh` — 打包脚本，自动提升 patch 版本，或接受指定版本；为兼容现有包名，输出仍为 `dist/douban-book-export-<版本>.zip`。
- `dist/` — 已打包的扩展。
- `icon*.png` — 图标。

## 打包

在仓库根目录运行：

```bash
./build.sh 2.2.0       # 指定版本
./build.sh            # 自动提升 patch 版本
./build.sh --no-bump  # 使用当前版本重新打包
```

上传包只包含扩展运行文件，不包含 README、隐私政策、测试或 Git 数据。

## 开发验证

使用 Node.js 22.22.2+、24.15.0+ 或 26+（具体范围见 `package.json`）：

```bash
npm ci
npm test
```

测试覆盖三站主页入口、分页解析、Excel 生成与读回、日期记录隔离、异常页面及取消导出。测试依赖不随扩展打包。
