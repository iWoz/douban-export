# 豆瓣读书导出助手 Plus

Chrome 扩展：在豆瓣读书个人页加一个按钮，**一键把「在读 / 读过 / 想读」三个书单全部导出到一个 Excel 文件**，
并带上 标记日期（评价时间）、我的评分、短评、标签，以及 想读→读完 / 在读→读完 的天数。

基于原「豆瓣导出助手」1.1 改造（原版只能把当前列表导成 txt）。

## 功能

- 一次点击抓取三个书单的全部分页，生成一个 `.xlsx`
- Excel 内含 5 个工作表：`全部`、`在读`、`已读`、`想读`、`说明`
- 每本书的字段：

  | 列 | 说明 |
  |---|---|
  | 状态 | 在读 / 已读 / 想读 |
  | 书名、作者、出版社、出版年、定价 | 从列表页「出版信息」拆出来，另保留原文一列 |
  | 我的评分(1-5) | 你打的星级，未评分为空 |
  | 短评、标签 | 你写的短评和打的标签 |
  | 标记日期 | 你标记 在读/读过/想读 的日期，即评价时间 |
  | 想读日期、开始在读日期、读完日期 | 见下文「阅读时长」 |
  | 想读→读完(天)、在读→读完(天)、在读至今(天) | 由上面三个日期相减得到 |
  | 豆瓣链接（可点击）、封面 | |

## 阅读时长是怎么算的

豆瓣一本书只保留**当前状态**的日期，标成「读过」以后，之前「想读」的日期就看不到了。

所以扩展在每次导出时，会把每本书各状态的日期记到浏览器本地存储（`chrome.storage.local`，不会上传）。
之后再导出时，用记录里的想读/在读日期和当前的读完日期相减，得到天数。

也就是说：

- 现在正处于「想读 / 在读」的书，这次导出就会把日期记下来，以后读完再导出就能算出时长；
- 历史上早就读完的书，没有想读日期，这几列为空。

**建议隔一段时间导出一次**，这样读完时就能算出完整的阅读时长。设置页可以查看 / 清空这份记录。

## 安装

Chrome 商店装的原版目录有完整性校验，不能直接改，所以用「加载已解压的扩展程序」：

1. 下载/克隆本仓库
2. 打开 `chrome://extensions`，右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本仓库目录
4. 如果装着原版「豆瓣导出助手」，建议先把它停用，避免页面上出现两个按钮

## 使用

1. 登录豆瓣，打开 `https://book.douban.com/mine`（会跳到 `/people/你的ID/`），或任意一个 在读 / 读过 / 想读 列表页
2. 点击用户名旁边的「一键导出三个书单 (Excel)」
3. 等三个书单抓完，点「下载 Excel」

每 15 本书要请求一页。短时间请求过多豆瓣会返回 403 甚至封 IP，书多的话请在扩展设置里把请求间隔调大（默认 1 秒）。

## 文件说明

- `manifest.json` — MV3 清单
- `export.js` — 抓取、解析、生成 Excel 的内容脚本
- `xlsx.full.min.js` — [SheetJS](https://sheetjs.com/) 社区版 0.20.3，本地打包，不依赖网络
- `modal.css` — 导出进度弹窗样式
- `options.html` / `options.js` — 设置页（请求间隔、阅读时长记录）
- `icon*.png` — 图标（16/32/48/128，另附 512 原图）
